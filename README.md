# 热点快报 Skill

一个面向商业话题的只读新闻检索与简报工作流。它从公开新闻中筛选最近 7 天的有效报道，去重、限制单一来源的占比，并输出短小、可点击、证据关联的新闻快报。

> 仓库不包含 API Key 或账号信息。连接器示例仅使用环境变量占位符；不要提交已填入密钥的配置文件。

## 适用场景

- 快速了解一家公司、行业、产品、技术或商业事件近 7 天的新进展。
- 为管理者准备短决策简报：识别已发生的变化、可能影响和需关注的下一步。
- 为内容团队发现可写选题、受众和切入角度。
- 在会议前或调研前获得一份受证据约束的新闻清单，而不是泛泛的趋势总结。

不用于政治选举、军事冲突、主权争议、武器部署或情报相关主题；这些主题会在检索前停止处理。

## 工作方式

```mermaid
flowchart LR
  A[主题与输出目标] --> B[验证只读新闻连接器]
  B --> C[近 7 天检索]
  C --> D[日期、URL 与标题校验]
  D --> E[去重、来源均衡与排序]
  E --> F[新闻清单 / 决策简报 / 选题雷达]
```

1. 确认主题及需要的输出类型。
2. 检查连接器是否提供只读的平台查询和内容检索能力。
3. 以最近 7 天为严格时间窗发起检索：默认快速模式只检索一次；只有明确要求时才使用深度模式的 6 个互补检索角度。
4. 仅保留标题、HTTP(S) 链接和发布日期齐全的记录；移除未来日期和时间窗外内容。
5. 规范化 URL、合并重复故事、限制单域名数量，并根据相关性、来源质量、时效、影响和新颖度排序。
6. 生成 0–3 条短摘要和最多 10 条可点击新闻；没有合格记录时明确说明。

## 输出模式

| 模式 | 用途 | 输出 |
| --- | --- | --- |
| `news_list` | 默认模式 | 近期新闻清单与短摘要 |
| `decision_brief` | 管理与业务判断 | 已发生变化、影响对象、机会/风险和建议动作 |
| `content_radar` | 内容策划 | 选题角度、目标受众、建议标题和内容切口 |
| `both` | 同时需要判断与选题 | 共享同一组经过筛选的新闻证据 |

所有专业结论必须绑定最终入选新闻；数据不足时减少输出项目，不编造热度、指标、市场份额或确定性预测。

## 配置连接器

Skill 需要一个兼容 MCP 的**只读**新闻检索连接器，至少应提供与以下能力等价的工具：

- `list_platforms`
- `search_platform_content`

将 `mcp.example.json` 复制到你的 MCP 宿主要求的位置，并在本地环境或密钥管理服务中设置变量：

```powershell
$env:OCTOPARSE_API_KEY = "仅在本地安全保存的密钥"
```

示例配置中的 `${OCTOPARSE_API_KEY}` 是占位符。`.gitignore` 已忽略本地连接器配置和环境文件。

## 结果格式与质量边界

每个新闻条目都使用原记录中的标题、来源、发布日期和 URL：

```text
1. [新闻标题](https://原文链接) — 来源 · YYYY-MM-DD
```

- 默认最终不超过 10 条，且同一域名最多 2 条。
- 结果是本次检索覆盖范围内的简报，不代表完整新闻覆盖或市场全貌。
- 不编造链接、引文、互动数据、因果关系或原记录中不存在的事实。
- 当没有合格记录时，返回“近 7 天未发现合格新闻”。

## 超大响应处理

正常情况下直接在内存中处理连接器结果。只有 MCP 宿主将超大响应保存为文件时，才使用：

```powershell
node scripts/compact_search_result.mjs --topic "主题" --input "响应文件.json"
```

该脚本一次性读取所有指定响应文件，提取标题、URL、域名、来源、发布日期、截断摘要和相关性，过滤时间窗外内容、去重并限制每域名最多 2 条，最多输出 40 条供后续筛选。它不需要密钥。
